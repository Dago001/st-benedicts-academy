# Security policy

Please report vulnerabilities privately to the school administrator (info@stbenedicts.edu.ng) rather than opening a public issue. Include the page/URL, steps to reproduce and the impact. We aim to acknowledge reports within 3 working days.

Operational checklist: change the default admin password, enable two-step verification for administrators, keep PHP and MariaDB patched, copy backups off-server, and review `logs/error.log` and the Audit Logs page regularly.
